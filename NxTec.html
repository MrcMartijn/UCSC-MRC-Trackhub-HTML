MRC Holland digitalMLPA Assay portfolio This track contains probes used in MRC Holland's digitalMLPA Assay portfolio. digitalMLPA combines the conventional MLPA technique with next-generation sequencing and enables the simultaneous analysis of up to 1600 genomic targets in a single assay. It is a targeted method for CNV and select SNV and methylation detection. Following multiplex PCR amplification, probe signals are quantified based on read count using an NGS platform.
